# ANONSURF (TOR SURFING SYSTEMWIDE)
If you want to be extra secure and run traffic through tor, you can use anonsurf. Anonsurf can be bundled with vpn usage (vpn first) in order to anonymize activity from all actors including ISP. Anonsurf without vpn (ISP can see tor only)
  
How to use:
```Bash
# Check if it is installed
sudo anonsurf status
  
# Start Anonsurf
sudo anonsurf start
  
# Stop Anonsurf
sudo anonsurf stop
```
